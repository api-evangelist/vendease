# Vendease

> Vendease is a Nigerian B2B food procurement platform (founded 2020, Y Combinator W21, backed by Partech Africa and TLcom) that helps restaurants, hotels, and other food businesses in Lagos buy fresh and processed food supplies, with Buy Now, Pay Later financing, supplier consolidation, cold-chain logistics, and 24-hour delivery. Vendease publishes no public developer API, no API documentation, and no client SDKs; its backend service APIs (procurement, payments, inventory, warehouse, tenant management) are internal-only. This file was generated by API Evangelist from the catalog profile — Vendease does not publish its own llms.txt.
